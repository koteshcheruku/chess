# 🎨 UI Guidelines (STRICT)

- Gradients
- Glassmorphism

## ✅ USE THIS INSTEAD

- Clean layout

Bad:
"Revolutionize your chess journey"

"Practice puzzles and improve your rating"

- Clear spacing

- Pieces draggable with touch
- Buttons large enough

- Highlight moves
- Show last move
